# 💳 Credit Card Fraud Detection

A machine learning project focused on detecting fraudulent credit card transactions using anomaly detection and classification techniques.

This project explores transaction-level patterns to distinguish legitimate transactions from potentially fraudulent ones and demonstrates an end-to-end machine learning workflow using Python and Jupyter Notebook.

## 🎯 Project Objective

Credit card fraud detection is a highly imbalanced classification problem where fraudulent transactions represent only a small proportion of total transactions.

The objective of this project is to:

- Analyze transaction data
- Understand patterns associated with fraudulent activity
- Handle class imbalance
- Engineer useful features
- Train machine learning models
- Evaluate fraud detection performance
- Identify transactions that are likely to be fraudulent
